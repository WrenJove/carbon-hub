# samples 目录说明

这个目录用来放本地测试用的单据图片，**内容不入库**（见根目录 .gitignore）。

按来源分三个子目录：

| 目录 | 放什么 |
|---|---|
| `own/` | 自己家的真实单据照片。含真实户号、住址，务必不要提交 |
| `extra/` | 其他自有单据（掩码过的、来源清楚的） |
| `public/` | 公开渠道找到的样例，用来测版式兼容性；演示时必须注明来源 |

仓库里只保留这个说明文件。想跑界面上的「内置样本」，把图片按上面的分类放进来即可，
界面会自动列出来。

⚠️ 放进来之前先确认：图片里有没有真实姓名、住址、户号、电话。
有的话要么涂掉，要么放到 `own/` 里（那个目录被 gitignore 挡住了）。
